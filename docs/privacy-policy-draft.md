# Privacy Policy

ApplyBoard stores application records locally in the browser's IndexedDB.

## Data collected

The extension can read the active browser tab only after the user clicks the extraction button. It may extract:

- Page URL and domain
- Job, degree, scholarship, or program title
- Organization, location, description, requirements, salary, tuition, deadlines, contact, notes, tags, and status

## Local storage

Application records, event history, settings, backups, and sync queue items are stored locally. The browser extension does
not send this data to external services unless the user enables an integration.

## Integrations

Cloud integrations are outside the MVP. Application data remains local in IndexedDB and can be exported for backup or analysis.

## User control

Users can export CSV/XLSX/JSON backups, restore backups, delete individual records, and clear local data before uninstalling.

## Security

The extension does not load remote executable JavaScript. Logs and sync errors should redact tokens, secrets, and API keys.
